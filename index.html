📘 Пошаговая инструкция

Цель: Заполнить табель в программе и перенести данные в ИСУ без рутинного ручного ввода.

Шаг 1. Настройка месяца и года

  • В верхней панели выберите нужный **месяц** и **год** из выпадающих списков.
  • Таблица автоматически перестроится под выбранный месяц (учтутся выходные и праздники).

Шаг 2. Проверка списка сотрудников

  • По умолчанию загружен список сотрудников вашей кафедры.
  • Если нужно изменить список — нажмите **«👥 Список сотрудников»** → **«📥 Загрузить (импорт)»** и выберите файл Excel с колонками «ФИО», «Таб. номер», «Должность».
  • Для резервной копии списка используйте **«📤 Выгрузить (экспорт)»** — он сохранит текущий список в файл Excel.

Шаг 3. Заполнение данных

  • Вариант А (быстрый): Нажмите **«⏱️ Автозаполнение табеля»**. Программа сама проставит часы и явки на основе должностей (инженер, лаборант, доцент и т.д.) и производственного календаря.
  • Вариант Б (пошаговый): Нажмите **«🤖 Авторежим по сотруднику: ВКЛ»**. Программа будет подсвечивать текущего сотрудника большой синей рамкой. Вы вводите данные, затем нажимаете **Пробел** (или ставите галочку) — и программа автоматически переходит к следующему сотруднику. Одиночный клик по другому сотруднику также включает для него авторежим (удобно, если нужно что-то поправить).
  • Вариант В (вручную): Просто кликайте по ячейкам и вводите значения (двойной клик — начать редактирование). Значения: «Ф» — факт работы, «В» — выходной, «Б» — больничный и т.д. Также можно тянуть за синий квадрат в углу ячейки для копирования значений (как в Excel).

Шаг 4. Генерация скрипта для ИСУ

  • Убедитесь, что все данные заполнены и проверены.
  • Нажмите кнопку **«⚡ Сгенерировать скрипт для ИСУ»**.
  • Программа скопирует в буфер обмена готовый JavaScript-код.

Шаг 5. Перенос данных в ИСУ

  • Откройте страницу заполнения табеля в ИСУ.
  • Нажмите F12 (или ПКМ → «Посмотреть код»), чтобы открыть консоль разработчика.
  • Перейдите на вкладку «Консоль» (Console).
  • Вставьте скопированный скрипт (Ctrl+V) и нажмите Enter.
⚠️ Если появилась ошибка:
«Warning: Don’t paste code into the DevTools Console that you don’t understand or haven’t reviewed yourself... Type "allow pasting" below and press Enter to allow pasting.»

Решение:
  1. В консоли (внизу, где мигает курсор) вручную (с клавиатуры) наберите фразу: allow pasting
  2. Нажмите Enter.
  3. После этого снова вставьте скрипт (Ctrl+V) и нажмите Enter. Ошибка больше не появится.

Это защитная мера браузера. Набирая текст вручную, вы подтверждаете, что понимаете, что делаете.

  • Дождитесь сообщения «✅ Заполнение завершено!» и проверьте, что данные встали верно.
  • Сохраните форму в ИСУ.

Дополнительные возможности

  • 🖌️ Заливка столбца — позволяет закрашивать столбцы вручную (например, выделить праздники или отпуска).
  • 📅 Календарь — открывает производственный календарь с праздниками (для сверки).
  • 📖 Шпаргалка — горячие клавиши и подсказки по работе.
Совет: Если что-то пошло не так — нажмите Ctrl+Z (Отмена) или Ctrl+Y (Повтор). История хранит до 50 последних действий.

📖 Шпаргалка по работе с табелем

1. Основные кнопки

  • ⏱️ Автозаполнение табеля — автоматически заполняет часы и явки для всех сотрудников на основе их должностей и производственного календаря.
  • 🤖 Авторежим по сотруднику — пошаговое заполнение. Включает режим, при котором большая рамка охватывает выбранного сотрудника. Вы вводите данные, ставите галочку «Готово» (или жмете Пробел), и система автоматически переходит к следующему сотруднику.
  • 📅 Календарь — показывает производственный календарь с праздниками и выходными.
  • 📖 Шпаргалка — открывает это окно с подсказками.
  • 👥 Список сотрудников — выпадающее меню с возможностью импорта/экспорта списка сотрудников (ФИО, Таб. номер, Должность) в формате Excel.

2. Горячие клавиши (работают при выделенных ячейках)

  • Пробел — поставить/снять галочку «Готово» для сотрудника, чья строка сейчас выделена большой рамкой.
  • Двойной Esc — принудительно выключить авторежим.
  • Delete / Backspace — очистить выделенные ячейки (значения).
  • Ctrl + C / Ctrl + V — копировать / вставить значения ячеек.
  • Ctrl + X — вырезать значения ячеек.
  • Enter — перейти к ячейке ниже (в режиме редактирования — сохранить и перейти).
  • F2 — начать редактирование выделенной ячейки.
  • Ctrl + Z / Ctrl + Y — отменить / повторить действие.

3. Управление мышью

  • Одинарный клик по ячейке — выделяет её (рисует тонкую синюю рамку). В авторежиме большая рамка сотрудника не сбрасывается.
  • Двойной клик по ячейке дня — открывает режим редактирования значения.
  • Двойной клик по столбцам «ФИО», «Таб. номер» или «Должность» — мгновенно включает авторежим для этого сотрудника.
  • Выделение мышью (зажать ЛКМ и тянуть) — выделяет диапазон ячеек.
  • Перетягивание за маркер (маленький синий квадрат в правом нижнем углу выделенной ячейки) — копирует значения вниз или в сторону, как в Excel.

4. Особенности интерфейса

  • Большая синяя рамка — показывает, для какого сотрудника сейчас открыт авторежим. Она охватывает все дни и итоговые столбцы.
  • Тонкая синяя рамка (пунктир) — показывает текущую активную ячейку, с которой вы работаете.
  • Синяя галочка — означает, что сотрудник полностью заполнен и проверен.
  • Синяя подсветка первых 5 колонок — появляется, когда в строке сотрудника есть хотя бы одно значение (день или часы).

ℹ️ ИСУ-Табель Экспресс

Назначение: Инструмент для быстрого учета рабочего времени сотрудников кафедры с возможностью генерации скрипта для автоматического заполнения в системе ИСУ. Создан, чтобы избавить вас от муторного ручного ввода в ИСУ.
